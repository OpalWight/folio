# Credits and licences

## Laptop product shot — `static/laptop/*.webp`

**Original work. No third-party model, photo or mockup asset is used.**

The laptop in the featured project cards and on the project pages is a 3D render
generated by `tools/laptop-render/`. The geometry is built procedurally in code —
rounded boxes for the lid and deck, an instanced grid of keycaps, a hinge barrel and
feet — and lit by an environment assembled in the same script. There is no downloaded
mesh, no scanned model, no purchased or scraped mockup, and no stock photography, so
there is no third-party licence to honour on the images themselves.

The device is a generic aluminium laptop. It carries no manufacturer logo, wordmark or
other branding, and is not modelled on the distinctive housing of any specific product.

Regenerate with:

```
npm run render:laptop      # then open http://localhost:5177/ and it writes static/laptop/
```

| File | What it is |
| --- | --- |
| `static/laptop/<pose>.webp` | 1960x1320 render with alpha, one per pose |
| `static/laptop/<pose>.json` | Where the screen plane landed in the frame; the source of the quads in `Laptop.svelte` |
